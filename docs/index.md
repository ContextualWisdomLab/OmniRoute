# OmniRoute

[![Ask DeepWiki](https://deepwiki.com/badge.svg)](https://deepwiki.com/ContextualWisdomLab/OmniRoute)

OmniRoute is an AI gateway for routing coding agents across multiple LLM providers with automatic fallback. This repository is ContextualWisdomLab's maintained fork of the upstream OmniRoute project; upstream project identity and licensing remain intact.
